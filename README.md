# JANSUVIDA – CSC Digital Services Portal

A customer-first digital service portal for CSC / Jan Seva Kendra operations.

## Current build

- Responsive premium homepage
- Service search
- Popular CSC service cards
- Government schemes section
- Customer login/register UI
- Application tracking UI
- WhatsApp contact CTA
- Mobile navigation

1. Laravel backend setup
2. Customer authentication and profiles
3. Service/category management
4. Online application workflow
5. Document upload and verification
6. UPI/payment integration
7. Customer dashboard and application tracking
8. Admin dashboard and reports
9. Notifications and support tickets
10. Security, testing and deployment
